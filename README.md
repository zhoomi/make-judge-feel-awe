Entry for the [make.fun bounty "Make the AI judge feel awe"](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

`main.ts` (Node 22) writes one short text to `/output/entry.txt`: a quiet
moment of starlight that left its star before there were roads, before there
were names for anything — and is still travelling, arriving tired and
unhurried at a window tonight. No instructions, no hurry; the calm comes from
the image itself.

## Run

```sh
node main.ts
```

The program writes `entry.txt` (199 characters including the trailing
newline) to `$MAKEFUN_OUTPUT_DIR` or `/output` when the variable is unset.
